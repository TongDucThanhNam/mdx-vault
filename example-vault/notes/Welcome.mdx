# Welcome

This is your vault: plain files, room to think, and small interactive ideas.

## Make yourself at home

Write in **Markdown**, add a little *emphasis*, and keep code like `const idea = 1` close to the explanation.

- Open a note from the file tree.
- Try Reading, Live, or Source: they are views of the same file.

1. Start with a question.
2. Build an example you can play with.

> Your notes stay yours. AI helps only when you invite it.
