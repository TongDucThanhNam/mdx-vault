# Binary Search

Binary search works **only when the array is sorted**. Thuật toán loại bỏ một nửa
không gian tìm kiếm sau mỗi lần so sánh, nên độ phức tạp là `O(log n)`.

## Static explanation

1. Đặt `low = 0`, `high = n - 1`
2. Lấy `mid = (low + high) / 2`
3. Nếu `arr[mid] == target` → xong
4. Nếu `arr[mid] < target` → `low = mid + 1`, ngược lại `high = mid - 1`
5. Lặp cho tới khi `low > high`

## Why sorted order matters

Nếu mảng chưa sort, phép so sánh ở giữa không cho biết nửa nào chứa target —
thuật toán fail một cách im lặng. Xem thêm [[Bayes Theorem]] về một loại "sai im lặng" khác.
