# GOAL-03 Safe Render

This note exercises the render trust boundary: safe HTML is sanitized, registry
components validate props, and unknown components render placeholders.

## HTML that must be stripped

The script tag below must not render or execute.

<script>alert(1)</script>

The `onclick` attribute below must be removed while the text remains.

<div onclick="alert('bad')">This div should remain without an event handler.</div>

This link must not keep a `javascript:` URL:

<a href="javascript:alert('bad')">Unsafe link URL</a>

## HTML that should remain

<details>
  <summary>Allowed details/summary</summary>

  Safe details content should render after sanitization.

</details>

| Element | Expected |
| --- | --- |
| table | renders |
| script | stripped |

<svg viewBox="0 0 80 40" width="160" height="80" role="img" aria-label="Allowed SVG circle">
  <circle cx="20" cy="20" r="14" fill="currentColor" onclick="alert('bad')" />
</svg>

## Registry validation

This valid counter should render:

<Counter initial={2} />

This invalid counter should render an inline warning card:

<Counter initial="abc" />

This unknown component should render a placeholder card:

<KhongTonTai />
